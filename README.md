## Merhaba, ben Beyza 👋

Abdullah Gül Üniversitesi'nde 4. sınıf Bilgisayar Mühendisliği öğrencisiyim. Sensörlerin, mikrodenetleyicilerin ve modellerin buluştuğu **uçtan uca sistemler** geliştiriyorum — firmware'den haberleşme protokolüne, backend'den arayüze kadar.

Şu sıralar üzerinde çalıştığım alanlar: gömülü sistemler, IoT telemetrisi, uç cihazda çalışan yapay zekâ ve otonom sistemler.

🌐 **[beyziki.github.io](https://beyziki.github.io)** · 📍 Kayseri, Türkiye
